[#eventing-examples]
= Eventing Examples

== General

This annex is informative.
It contains examples for the events defined in Clause xref:eventing.adoc[Eventing].

All examples use the following objects:

.Objects used in the examples
[%autowidth,width="100%",cols="30%,70%",options="header",]
|===
|Object |Identification
|Base URL of the service |`\https://aas.example.com`
|Asset Administration Shell |`\https://example.com/ids/aas/7600_5912_3951_6917`
|Asset |`\https://example.com/ids/asset/7600_5912_3951_6917`
|Submodel |`\https://example.com/ids/sm/4210_0802_6152_5421` with semanticId `\https://example.com/semantics/OperationalData/1/0`
|Concept Description |`\https://example.com/ids/cd/temperature`
|===

Parts that are identical for all Contents are repeated to keep every example complete.
