[#eventing-examples]
= Eventing Examples

== General

This annex is informative.
It contains examples for the events defined in Clause xref:eventing.adoc[Eventing].

All examples use the following objects:

.Objects used in the examples
[%autowidth,width="100%",cols="30%,70%",options="header",]
|===
|Object |Identification
|Base URL of the service |`\https://aas.example.com`
|Asset Administration Shell |`\https://example.com/ids/aas/7600_5912_3951_6917`
|Asset |`\https://example.com/ids/asset/7600_5912_3951_6917`
|Submodel |`\https://example.com/ids/sm/4210_0802_6152_5421` with semanticId `\https://example.com/semantics/OperationalData/1/0`
|Concept Description |`\https://example.com/ids/cd/temperature`
|===

== SubmodelElement Events

=== io.admin-shell.submodelelement.created.v1

A SubmodelElementCollection with two Properties was added.
The data contains the SubmodelElementCollection with Content _Metadata_, i.e. without its child elements.
The child elements result in no events of their own and can be retrieved with `GetSubmodelElementByPath`.

[source,json]
----
{
  "specversion": "1.0",
  "id": "0192a3f6-2a00-7005-a1b2-3c4d5e6f7a8b",
  "type": "io.admin-shell.submodelelement.created.v1",
  "source": "https://aas.example.com",
  "subject": "(Submodel)https://example.com/ids/sm/4210_0802_6152_5421, (SubmodelElementCollection)Maintenance",
  "time": "2026-09-29T11:00:00.000000Z",
  "datacontenttype": "application/json",
  "dataschema": "https://admin-shell.io/aas/API/Events/SubmodelElementEventData/3/3",
