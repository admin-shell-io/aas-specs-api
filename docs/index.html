About

This repository contains the normative OpenAPI specifications for the Asset Administration Shell (AAS) HTTP/REST APIs. The specifications are maintained by the Industrial Digital Twin Association (IDTA).

Documentation: Each API can be viewed using Swagger UI (interactive) or Redoc (documentation-focused). Click on the respective buttons to explore the APIs.
